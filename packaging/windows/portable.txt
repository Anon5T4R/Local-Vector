Local Vector portable mode

While this file sits next to localvector.exe, Local Vector keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the LocalVectorData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Local Vector with its
settings. The first time LocalVectorData is created, any settings already in
%APPDATA%\LocalVector are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Local Vector loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\LocalVector) instead.
If LocalVectorData can't be written (for example on a read-only drive), Local Vector logs a
warning and uses %APPDATA%\LocalVector instead.
